explanation
1. git checkout -> used to switch between different branches in your local repo
2. git pull origin -> downloads content from a remote repository and updates your local branch with the latest changes
3. git diff -> Compares the differences between your current branch and another specified branch
4. git add ,commit-> Stages changes in your working directory and staging area,showing which files have been modified or are ready to be commited
5. git log -> shows the history of all commits made in the repository,which is useful for finding specific commit ID to perform resets
6. git reset -> used to unstage changes from a file
